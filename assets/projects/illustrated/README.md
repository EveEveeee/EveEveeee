# 中文项目封面

GitHub 主页「精选项目」区域的六张图画封面，与翻小译封面采用同一人物 IP、奶油色背景、绒毛材质和圆角细边框。每张封面使用不同动作与项目相关道具，主页继续采用两列、每张 49% 宽度的排列。

这些图片于 2026 年 10 月 12 日使用内置 imagegen 生成。`covers.json` 记录中文文案、项目阶段、配色和动作；`art-direction.txt` 记录全系列视觉约束；各张图片旁的 `.prompt.txt` 文件保存完整生成提示词。
